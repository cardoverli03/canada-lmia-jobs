# Cardo Careers

Filtered, organized sector lists of Canadian employers with approved LMIAs,
built from official Government of Canada open data, for Cardo Careers digital products.

**Agents: read [`BIBLE.md`](BIBLE.md) first — it contains the full business context,
data source documentation, product spec, rules and decisions log.**

## Quick facts

- Core data: ESDC TFWP Positive LMIA Employers List, 2026 Q1 (English) — 8,790 clean entries, TEER/SkillLevel tagged from official IRCC table
- Built sectors (11): agriculture 2,270 | hospitality-food-service 1,202 | construction 1,038 | tech-it 546 | transport-trucking 503 | healthcare-nursing 364 | office-admin 329 | retail-sales 295 | cleaning-landscaping 248 | food-processing 124 | fish-seafood 64 — parts of max 200 entries each
- Regenerate: `python3 scripts/build_sectors.py`
